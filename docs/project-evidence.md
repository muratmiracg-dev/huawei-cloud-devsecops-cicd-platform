# Project Evidence Checklist

Only mark an item complete when a reproducible artifact exists.

## Local

- [ ] CI test run with all tests passing
- [ ] coverage at or above the configured threshold
- [ ] both images build successfully
- [ ] Docker Compose health checks pass
- [ ] smoke test creates an order

## Huawei Cloud

- [ ] CodeArts pipeline run
- [ ] private SWR image repositories and immutable tags
- [ ] CCE development deployment
- [ ] CCE production deployment with approval
- [ ] AOM cluster and workload monitoring
- [ ] custom request and latency metrics
- [ ] triggered alarm test
- [ ] rollback demonstration

## Portfolio

- [ ] architecture diagram
- [ ] README with exact opening instructions
- [ ] sanitized screenshots
- [ ] two- to three-minute demo
- [ ] executive project report
- [ ] LinkedIn project entry

Cloud evidence is intentionally unchecked until the account-side deployment is
performed and verified.
